# Privacy Policy for APEX PREDATOR & AI PILOT Discord Application

**Last Updated:** September 29, 2026

Welcome to **APEX PREDATOR** ("the Application", "the Bot"), operated by the server leadership ("we", "our", "us"). We are committed to protecting your privacy. This Privacy Policy explains how information is collected, used, and safeguarded when you interact with our Discord Bot.

---

## 1. Information We Collect

When you use the Bot within a Discord server or direct message, we may collect and process the following minimal data necessary for functionality:
- **Discord User Identification:** User ID, Username, and Avatar URL (for leaderboard tracking, role assignments, and operator profile displays).
- **Server Data:** Guild ID, Channel IDs, and Role IDs (for permission verification and channel routing).
- **User-Provided Inputs:** Activision Gamertags, Clan Tags, Support Ticket messages, and command arguments submitted voluntarily via Modals or chat commands.
- **Message Content:** Inspected in real-time strictly for Auto-Mod security (anti-spam, secret API key protection) and immediate command processing. We do **not** store or archive general user chat messages.

---

## 2. How We Use Collected Information

The collected data is strictly utilized to:
- Grant verified roles and deliver server access upon verification.
- Render operator cards in community gamer-tag channels.
- Route and manage private support ticket channels.
- Prevent unauthorized access, malicious spam, and automated token leaks.
- Compile aggregate, anonymized server activity metrics.

---

## 3. Data Storage & Security

- **Storage:** All configuration data and ticket records are stored in secure local/cloud SQLite databases with restricted access.
- **Security:** We apply strict industry-standard access controls. We never sell, trade, or transfer your personal data to third parties.
- **Data Retention:** Data is retained only as long as you remain a member of the server or until an account deletion request is made.

---

## 4. Third-Party Services

The Application interacts with:
- **Discord API:** Subject to [Discord's Privacy Policy](https://discord.com/privacy) and [Developer Terms of Service](https://discord.com/developers/docs/policies-and-agreements/developer-terms-of-service).

---

## 5. Data Deletion & User Rights

You have the right to request the deletion of your stored user data (such as gamer tags or ticket history) at any time. To request data removal:
- Open a support ticket via `/ticket-setup` or `#🎫・support-desk` in the server.
- Contact the server administrators directly.

---

We may update this Privacy Policy from time to time. Continued use of the Application signifies acceptance of any modifications.
